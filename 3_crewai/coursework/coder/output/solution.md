I wrote a Python program in `calculate_series.py` that computes the first 1,000,000 terms of the alternating series

`1 - 1/3 + 1/5 - 1/7 + ...`

and multiplies the result by 4.

I then ran the script in the sandbox, and the output was:

`3.1415916535897743`

This is the computed approximation of π from 1,000,000 terms.
